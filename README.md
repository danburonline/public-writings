# Public Writings

This repository hosts public writings by Daniel Burger: essays, papers, patents, and books. Everything is written in LaTeX using a unified template system in `_templates/`. See [`_templates/README.md`](_templates/README.md) for template documentation.

Contributions welcome — these are living documents, continuously updated post-publication.

> **Note:** Work-in-progress documents live in private Git repositories and are linked here as submodules. Their source is not published until finalised and promoted into this repository. Patents are stricter still: content stays confidential until a provisional application is filed (see below).

## Repository Structure

```txt
Writings/
├── 001_patents/    # Technical inventions (confidential until filed)
├── 002_papers/     # Academic papers and preprints
├── 003_books/      # Extended works with chapter structure
├── 004_essays/     # Long-form scientific/philosophical writing
└── _templates/     # Shared LaTeX templates
```
